## 1. Как устроена программа — знакомство с модулями

Любая большая программа делится на **модули** — отдельные файлы `.py`, каждый из которых отвечает за свою часть работы. Это называется **принцип разделения ответственности**.

### Структура нашего проекта:

```
chromomath-modeling/
├── main.py              ← Запускаем эту программу. Главное окно.
├── help_module.py       ← Окна «Справка» и «О программе»
├── visualize/
│   ├── hmm_module.py    ← Математические функции
│   ├── v1d.py           ← Окно «1D-визуализация»
│   └── v2d.py           ← Окно «2D-визуализация»
└── data/
    ├── data.txt         ← Файл с числами
    └── data_generator.py ← Программа для генерации чисел
```

### Аналогия из жизни

Представьте строительство дома:
- `main.py` — прораб, который координирует всех
- `hmm_module.py` — математик, считает числа
- `v1d.py`, `v2d.py` — дизайнеры, рисуют красиво
- `help_module.py` — консультант, объясняет как пользоваться

## 3. Функции — основа переиспользования кода

**Функция** — это именованный блок кода, который можно вызвать много раз.

### Синтаксис

```python
def имя_функции(параметр1, параметр2):
    """Документация функции (необязательно, но полезно)"""
    # тело функции
    return результат  # что возвращает функция
```

### Из кода проекта — файл `visualize/hmm_module.py`:

```python
def ker(n):
    """Рекурсивная сумма цифр числа"""
    while n >= 10:
        n = sum(int(d) for d in str(n))
    return n
```

Разберём эту функцию пошагово:

| Строка | Что делает |
|---|---|
| `def ker(n):` | Объявляем функцию с именем `ker`, принимающую параметр `n` |
| `"""Рекурсивная сумма цифр числа"""` | Документация (docstring) — объяснение что делает функция |
| `while n >= 10:` | Цикл: повторяем пока `n` не стало однозначным |
| `n = sum(int(d) for d in str(n))` | Складываем все цифры числа |
| `return n` | Возвращаем результат |

### Как работает `ker(38)`:

```
Шаг 1: n = 38, str(38) = "38", цифры: '3', '8'
        int('3') = 3, int('8') = 8
        sum([3, 8]) = 11 → n = 11

Шаг 2: n = 11, str(11) = "11", цифры: '1', '1'
        sum([1, 1]) = 2 → n = 2

Шаг 3: n = 2, условие 2 >= 10 → ЛОЖЬ → выходим из цикла
        return 2
```

### Функции с несколькими параметрами:

```python
def model_ker_sum_squares(x, y):
    """Ker для суммы квадратов"""
    return ker(x * x + y * y)


def model_ker_sum_cubes(x, y):
    """Ker для суммы кубов"""
    return ker(x * x * x + y * y * y)
```

**Вызов функций:**
```python
result = model_ker_sum_squares(3, 4)
# x=3, y=4
# x*x + y*y = 9 + 16 = 25
# ker(25) = 2+5 = 7
# result = 7
```

## 5. Списки и генераторы

**Список** (`list`) — упорядоченная коллекция элементов.

```python
numbers = [1, 8, 27, 64, 125]  # список кубов
numbers[0]    # 1   — первый элемент (индекс с нуля!)
numbers[-1]   # 125 — последний элемент
len(numbers)  # 5   — длина списка
```

### Из кода проекта — `data/data_generator.py`:

```python
def generate_cubes(count=1500):
    return [i**3 for i in range(1, count + 1)]
```

Эта конструкция называется **генератор списка** (list comprehension):

```python
[i**3 for i in range(1, count + 1)]
```

Читается как: «Возьми каждое `i` из диапазона от 1 до count, и для каждого вычисли `i³`».

Это эквивалентно:
```python
result = []
for i in range(1, count + 1):
    result.append(i**3)
return result
```

### Ещё генераторы из проекта:

```python
# В функции ker — сумма цифр:
n = sum(int(d) for d in str(n))
# Берём строку числа, каждый символ d преобразуем в int, суммируем

# Пример для n = 38:
# str(38) = "38"
# for d in "38" → d="3", затем d="8"
# int("3")=3, int("8")=8
# sum([3, 8]) = 11
```

## 6. Работа с файлами

Программа хранит числа в файле `data/data.txt` и читает их при запуске.

### Запись в файл — `data/data_generator.py`:

```python
with open(file_path, "w") as f:        # "w" = write (запись)
    for cube in cubes:
        f.write(f"{cube}\n")            # пишем каждое число на новой строке
```

- `with open(...) as f:` — безопасное открытие файла (автоматически закроется)
- `"w"` — режим записи (перезапишет файл)
- `f.write(...)` — записывает строку
- `\n` — символ новой строки
- `f"{cube}\n"` — f-строка: вставляет значение переменной в текст

### Чтение из файла — `visualize/v1d.py`:

```python
def load_data():
    try:
        file_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "data.txt")
        with open(file_path, "r") as file:            # "r" = read (чтение)
            return [int(line.strip()) for line in file.readlines()]
    except FileNotFoundError:
        return [i**3 for i in range(1, 1001)]         # запасной вариант
```

Разберём:
- `file.readlines()` — читает все строки в список `["1\n", "8\n", "27\n", ...]`
- `line.strip()` — убирает пробелы и `\n` с краёв строки
- `int(...)` — преобразует строку `"27"` в число `27`

### Режимы открытия файлов:

| Режим | Что делает |
|---|---|
| `"r"` | Чтение (файл должен существовать) |
| `"w"` | Запись (создаёт новый или перезаписывает) |
| `"a"` | Дозапись в конец файла |

## 9. Переменные tkinter и реактивный интерфейс

В обычном Python, если изменить переменную, интерфейс об этом не знает. Tkinter решает это через специальные **переменные-обёртки**:

| Класс | Тип данных | Пример |
|---|---|---|
| `tk.StringVar` | строка | `tk.StringVar(value="Привет")` |
| `tk.IntVar` | целое | `tk.IntVar(value=42)` |
| `tk.DoubleVar` | дробное | `tk.DoubleVar(value=3.14)` |
| `tk.BooleanVar` | логическое | `tk.BooleanVar(value=True)` |

### Чтение и запись:

```python
var = tk.IntVar(value=10)
print(var.get())     # прочитать: 10
var.set(20)          # изменить на 20
```

### Связывание с виджетом:

```python
scale_factor = tk.DoubleVar(value=1.0)

    ctrl_frame,
```

Теперь когда пользователь двигает ползунок — `scale_factor` автоматически меняется. И наоборот: `scale_factor.set(2.0)` переместит ползунок.

### Реактивность через `trace_add` — ключевой паттерн проекта:

```python
# Из v1d.py:
for var in [selected_vis, selected_palette, mod_n, rainbow_cycle,
            scale_factor, bar_width, rotation, spiral_density, spiral_radius_factor]:
    var.trace_add("write", lambda *_: draw())
```

`trace_add("write", callback)` означает: «При каждом изменении этой переменной — вызвать функцию `callback`».

Это мощный паттерн: пользователь двигает ползунок → переменная меняется → автоматически вызывается `draw()` → график перерисовывается. Всё без кнопки «Обновить»!

```python
def draw_columns():
    canvas.delete("all")                       # сначала очищаем
    w, h = canvas.winfo_width(), canvas.winfo_height()  # размер холста
    if w <= 1 or h <= 1:                       # холст ещё не отрисован

    max_val = max(data)
    num_bars = min(100, len(data))             # не более 100 столбцов
    bar_w = (w / num_bars) * bar_width.get()  # ширина одного столбца

    for i in range(num_bars):
        idx = int(i * len(data) / num_bars)
        val = data[idx]
        height = (val / max_val) * (h - 50) * scale_factor.get()
        x0 = i * (bar_w + spacing)
        y0 = h - height        # Y растёт вниз! Верх столбца — наверху
        x1 = x0 + bar_w
        y1 = h                 # низ столбца — нижний край холста
        color = get_color(idx, val)
        canvas.create_rectangle(x0, y0, x1, y1, fill=color, outline="")
```

## 11. Математические вычисления и цвет

### Цветовая система HEX

Цвет в tkinter задаётся строкой `"#RRGGBB"`, где RR, GG, BB — шестнадцатеричные числа от 00 до FF (0–255 в десятичной системе).

```python
"#FF0000"  # чистый красный (R=255, G=0, B=0)
"#00FF00"  # чистый зелёный
"#0000FF"  # чистый синий
"#FFFFFF"  # белый
"#000000"  # чёрный
"#CCCCCC"  # серый
```

Для вычисления цвета используем f-строку с форматированием `:02x` — перевод числа в HEX с минимум 2 символами:

```python
r, g, b = 255, 128, 0
color = f"#{r:02x}{g:02x}{b:02x}"   # "#ff8000" — оранжевый
```

### Радужный градиент — HSV в RGB (`v1d.py`):

**HSV** — другая цветовая модель: Hue (оттенок 0°–360°), Saturation (насыщенность), Value (яркость).

```python
def hsv_to_rgb(h, s=1.0, v=1.0):
    """Конвертация HSV в RGB"""
    c = v * s
    x = c * (1 - abs((h / 60) % 2 - 1))
    m = v - c
    r, g, b = {
        0: (c, x, 0),
        1: (x, c, 0),
        2: (0, c, x),
        3: (0, x, c),
        4: (x, 0, c),
        5: (c, 0, x),
    }[int(h / 60) % 6]
    return f"#{int((r + m) * 255):02x}{int((g + m) * 255):02x}{int((b + m) * 255):02x}"
```

Использование:
```python
ratio = (value % cycle) / cycle   # позиция 0.0 ... 1.0
hue = ratio * 360                  # оттенок 0° ... 360°
color = hsv_to_rgb(hue)
```

### Модульная арифметика (`%` — остаток от деления):

```python
7 % 3   # = 1  (7 = 3×2 + 1)
10 % 3  # = 1  (10 = 3×3 + 1)
9 % 3   # = 0  (9 = 3×3 + 0)
```

В проекте `%` используется в двух местах:
1. `value % cycle` — определяет позицию в цикле радуги
2. `value % n` — определяет дискретный цвет в модели Mod N

### Полярные координаты в спирали (`v1d.py`):

```python
angle = i * angle_step + math.radians(rotation.get())
radius = (val / max_val) * max_radius
x = center_x + radius * math.cos(angle)  # x = cx + r·cos(θ)
y = center_y + radius * math.sin(angle)  # y = cy + r·sin(θ)
```

Формула перехода из полярных координат (r, θ) в декартовы (x, y):
- `x = center_x + r · cos(θ)`
- `y = center_y + r · sin(θ)`

## 12. Обработка ошибок (try/except)

Программа должна продолжать работу даже если что-то пошло не так. Для этого Python использует конструкцию `try/except`.

### Синтаксис:

```python
try:
    # код, который может вызвать ошибку
except ТипОшибки:
    # что делать если ошибка произошла
```

### Из `v1d.py` — загрузка файла:

```python
def load_data():
    try:
        file_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "data.txt")
        with open(file_path, "r") as file:
            return [int(line.strip()) for line in file.readlines()]
    except FileNotFoundError:
        return [i**3 for i in range(1, 1001)]  # файл не найден — генерируем сами
```

### Из `v1d.py` — чтение числового параметра:

```python
try:
    cycle_val = int(rainbow_cycle.get())   # пользователь мог ввести "abc"
    cycle = max(cycle_val, 2)
except ValueError:
    cycle = 2   # если не число — используем значение по умолчанию
```

### Несколько типов ошибок:

```python
except (tk.TclError, ValueError):
    n = 2
```

Скобки позволяют обработать несколько типов ошибок одним блоком.

### Распространённые типы ошибок:

| Ошибка | Когда возникает |
|---|---|
| `ValueError` | `int("abc")` — нельзя преобразовать в число |
| `FileNotFoundError` | Файл не существует |
| `ZeroDivisionError` | Деление на ноль |
| `IndexError` | Обращение за пределы списка `a[100]` при len=5 |
| `KeyError` | Ключ не найден в словаре |

## 13. Лямбда-функции

**Лямбда** — анонимная функция в одну строку.

### Синтаксис:

```python
lambda параметры: выражение
```

### Из `main.py` — горячие клавиши:

```python
root.bind_all("<F1>", lambda event: show_help())
root.bind_all("<Control-F1>", lambda event: show_about())
```

Здесь `lambda event: show_help()` — это функция, которая:
- Принимает параметр `event` (информация о нажатии)
- Вызывает `show_help()` (игнорируя `event`)

Без лямбды пришлось бы писать:
```python
def on_f1(event):
    show_help()

root.bind_all("<F1>", on_f1)
```

Лямбда компактнее, когда функция используется только в одном месте.

### Из `v2d.py` — трассировка переменных:

```python
selected_palette.trace_add("write", lambda *_: draw_model())
```

`lambda *_: draw_model()` — функция, которая принимает любые аргументы (они нас не интересуют — `_`) и вызывает `draw_model()`.

### Из `v2d.py` — кнопка:

```python
ttk.Button(
    ctrl_frame,
    text="Построить модель",
    command=lambda: draw_model()
).grid(...)
```

Здесь лямбда нужна, потому что `command=` ожидает функцию без аргументов, а нам нужно просто вызвать `draw_model()`.
